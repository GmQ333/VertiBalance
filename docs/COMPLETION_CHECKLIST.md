# 需求完成核对表

本表以 `spec.md` 第 5 章的 21 项核心能力为准，记录可验证实现位置。

| 需求 | 实现证据 |
| --- | --- |
| 5.1 患者账户与登录 | `POST /auth/register`、`POST /auth/login`；登录/注册 Web 界面 |
| 5.2 智能问诊 | `/consultations` 会话和消息接口；上下文持久化与会话串行队列 |
| 5.3 危险信号筛查 | `screenRisk` 固定规则 + 管理员配置规则；规则结果只升不降 |
| 5.4 风险评估与分诊 | `buildReport` 生成四级风险、科室和时效；确定性表述拦截 |
| 5.5 挂号推荐与移交 | 实时号源、唯一性事务、取消释放号源、医生授权队列 |
| 5.6 问诊报告 | 问诊结束自动生成、历史查询、患者/医生权限隔离 |
| 5.7 健康科普 | 患者知识页、管理端发布/下线、与报告分开展示 |
| 5.8 患者随访 | 任务列表、评分/文本/用药反馈、异常规则、通知医生 |
| 5.9 医生账户与登录 | 管理员创建、资质字段、待审核/启用/禁用状态 |
| 5.10 医生工作台 | 挂号授权队列、风险排序、实时数量统计 |
| 5.11 AI 问诊资料 | 原始对话、报告、危险标记、补充文件；访问自动审计 |
| 5.12 医生辅助分析 | `/doctor/patients/:id/ai-analysis` 六字段结构化模型输出 |
| 5.13 患者记录 | 历史问诊、报告、处置、随访和上传资料聚合接口 |
| 5.14 接诊与处置 | 临床诊断、检查、治疗、用药、康复、复诊、计划持久化 |
| 5.15 医生随访任务 | 医生创建任务、患者通知、反馈与异常标记 |
| 5.16 用户与角色管理 | 管理端列表、创建、审核、启用/禁用和后端 RBAC |
| 5.17 医生与排班 | 科室、时段、号源、冲突校验、关闭/开放 |
| 5.18 模型管理 | 版本新增、公网 HTTPS 校验、连通性验证、激活、会话版本固定、调用监控 |
| 5.19 知识库管理 | 科普 CRUD、危险规则新增/启停并即时生效 |
| 5.20 运营统计 | 问诊、转化、高风险、时长、接诊、随访、模型、反馈八类指标 |
| 5.21 审计与安全 | 登录、越权、资料查看、修改、模型、上传下载日志；无修改/删除接口 |

额外 DFX 证据：

- 密码采用 `scrypt`；令牌使用 HMAC-SHA256，生产环境强制 `AUTH_SECRET`。
- 模型请求 30 秒超时且位于持久化事务之外。
- 文件仅允许 PDF/JPG/PNG、单文件 5MB，存储目录不公开。
- 站内提醒调度器每分钟扫描未来 24 小时的挂号和随访任务。
- `npm test` 覆盖密码、令牌、防篡改、规则、结构化模型输出和事务持久化。
- `scripts/smoke.mjs` 覆盖三角色核心业务闭环和越权拦截。
